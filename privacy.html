นโยบายความเป็นส่วนตัว

ระบบประกาศกลาง (Discord Bot)

มีผลตั้งแต่วันที่ 2 ตุลาคม 2569

1. ข้อมูลที่เกี่ยวข้องกับการทำงาน

เมื่อมีการใช้คำสั่งกับบอท ระบบอาจได้รับข้อมูลจาก Discord ที่จำเป็นต่อการทำงาน เช่น Discord User ID, ชื่อผู้ใช้, Server ID, Channel ID และข้อมูลของคำสั่งที่ผู้ใช้ส่งให้บอท

2. การใช้ข้อมูล

ข้อมูลดังกล่าวใช้เพื่อประมวลผลคำสั่ง ส่งประกาศไปยังช่องที่ผู้ใช้กำหนด ตรวจสอบสิทธิ์ และแก้ไขปัญหาการทำงานของบอท

3. การจัดเก็บข้อมูล

บอทเวอร์ชันนี้ไม่ได้จัดทำฐานข้อมูลเพื่อเก็บประวัติคำสั่งหรือข้อความประกาศอย่างถาวรโดยตัวบอทเอง ข้อมูลที่ Discord หรือผู้ให้บริการโฮสต์เก็บไว้จะอยู่ภายใต้นโยบายของผู้ให้บริการนั้น

4. การเปิดเผยข้อมูล

บอทจะไม่ขายหรือให้เช่าข้อมูลส่วนบุคคลแก่บุคคลอื่นเพื่อการโฆษณา อย่างไรก็ตาม การทำงานของ Discord และบริการโฮสต์อาจเกี่ยวข้องกับผู้ให้บริการภายนอกตามข้อกำหนดของบริการเหล่านั้น

5. ความปลอดภัย

ผู้ดูแลบอทต้องเก็บ Bot Token เป็นความลับและไม่เผยแพร่ต่อบุคคลอื่น หาก Token ถูกเปิดเผยควรสร้าง Token ใหม่ทันทีผ่าน Discord Developer Portal

6. สิทธิและคำขอเกี่ยวกับข้อมูล

สำหรับคำขอเกี่ยวกับข้อมูลที่เกิดขึ้นภายในเซิร์ฟเวอร์ ให้ติดต่อผู้ดูแลเซิร์ฟเวอร์ Discord ที่ติดตั้งบอท ซึ่งเป็นผู้ควบคุมการตั้งค่าและการใช้งานบอทในเซิร์ฟเวอร์นั้น

7. การปรับปรุงนโยบาย

นโยบายนี้อาจได้รับการปรับปรุงเมื่อมีการเปลี่ยนแปลงระบบหรือแนวทางการจัดการข้อมูล โดยจะแสดงวันที่ปรับปรุงไว้บนหน้านี้
